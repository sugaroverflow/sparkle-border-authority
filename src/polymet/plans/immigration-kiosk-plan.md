# Immigration Kiosk Application Plan

## User Request
Design a complete visual system and UI for a self-service Immigration Kiosk web application for the "Ration Club Border Control" event. The app should have a sci-fi spaceport terminal aesthetic with subtle cute celestial elements, running on iPad in kiosk mode.

## Important Notes
- **Visual Style**: Sci-fi spaceport terminal with institutional UI patterns
- **Color Palette**: Midnight navy/deep space blue, soft lilac, pastel pink, silver/white, glowing accents
- **Typography**: Condensed sans serif for official feel, rounded sans for friendly messages
- **Animations**: Scanning beams, blinking cursors, twinkling stars, glow effects, sparkles
- **Target Device**: iPad in kiosk mode (tablet-optimized layout)
- **Tone**: Official and credible but with whimsical celestial touches
- **Document Types**: Citizen Passport, Border-Issued Passport, Visitor Passcard, Photo Permit
